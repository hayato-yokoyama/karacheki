# Tamagui v2 移行の目視確認（#54）

Tamagui のバージョンアップは **UI の崩れが目視でしか検出できない**。
型チェックもテストも「崩れていないこと」を保証しないので、この手順で全画面を見る。

v3 移行でも同じ確認が要るので、チェックリストとして残しておく。

## 今回やったこと / やっていないこと

| | |
| --- | --- |
| やった | `tamagui` 1.144.4 → 2.7.7、アイコンを `lucide-react-native` へ置換 |
| やっていない | テーマの再生成（`theme-output.ts` は無変更 = テーマの値は 1 つも変わらない） |
| やっていない | config v5 への移行（media 名・style デフォルトが変わるので v3 移行時にまとめる） |

つまり **崩れるとしたらコンポーネント側の実装差分か、置き換えたアイコン**。
テーマの色が変わって見えたら、それは想定外なので報告してほしい。

## 確認のしかた

Simulator で足りる。EAS に投げる前にここで切り分ける。

```sh
npm run ios      # prebuild → CocoaPods → xcodebuild → 起動
```

iOS 26 Simulator はヘルスケアも動くので、体重まわりの画面もここで確認できる（#46 参照）。

ライト／ダークの切り替えは Simulator の設定から。

```sh
xcrun simctl ui booted appearance dark
xcrun simctl ui booted appearance light
```

## 重点的に見るところ

今回の変更で**実際に差分が出うる**のはこの 5 箇所。ここだけは先に見る。

1. **タブバーのアイコン**（`app/(tabs)/_layout.tsx`）
   `Home` → lucide の `House` はパスが変わっていて、**家の形が微妙に違う**。
   サイズは `size="$1"`（20px）を数値の 20 に置き換えたので同じはず。
   選択中・非選択中の色が従来通りか。
2. **ヘルスケアエラー画面の手順リスト**（`components/errorHealthData.tsx`）
   v2 で `ListItem` の `fontSize` / `fontWeight` がテキストに効かなくなったため
   `SizableText` で包んだ。見出しが太字か、手順 1〜5 が従来通り小さめの文字か。
   ヘルスケアのアクセスを一度 OFF にすると出せる。
3. **グラフ画面の期間切替タブ**（`app/(tabs)/graph/index.tsx`）
   v2 で `Tabs.List` の `separator` prop が無くなったので `Separator` を手で挟んだ。
   1ヶ月 / 3ヶ月 / 6ヶ月 / 1年 の**区切り線の位置と本数**（3 本）が従来通りか。
4. **写真一覧の選択チェックバッジ**（`app/(tabs)/photo/index.tsx`）
   `$background` トークンを `theme.background.val` の実値に置き換えた。
   ライト／ダークそれぞれでバッジの中のチェックが背景色と同じか。
5. **Button / ListItem に渡しているアイコン**（削除ボタン、写真追加、体重の入力など）
   Tamagui が icon に色とサイズを注入する仕組みに乗ったままなので、
   **サイズが極端に大きい / 小さい、色が黒のまま**なら注入が効いていない。

## 「Can't find Tamagui configuration」で起動しないとき

テーマの context は `@tamagui/web` のモジュールインスタンスに紐づくので、
**node_modules に `@tamagui/web` が 2 つ以上あると、親テーマが見つからず落ちる**。
バージョンが全部揃っていても、npm が hoist に失敗して物理コピーが増えれば同じことが起きる。
型チェックもバンドルも通ってしまい、実機・Simulator で起動して初めて分かる。

```sh
# 1 以外ならアウト
find node_modules -path "*@tamagui/web/package.json" | wc -l

npx @tamagui/cli check   # バージョン不一致のほうはこれで分かる
```

増えていたら、部分的な `npm install` を重ねたのが原因なので作り直す。

```sh
rm -rf node_modules package-lock.json && npm install && npm dedupe
```

`npx expo export --platform ios` のモジュール数も目安になる。
重複していると倍増する（正常時 5,350 → 重複時 11,407 だった）。

## 崩れていたら

原因を切り分けやすいようにコミットを分けてある。

| 症状 | 疑うコミット |
| --- | --- |
| アイコンだけおかしい | `♻️ アイコンを @tamagui/lucide-icons から lucide-react-native へ` |
| 全体的におかしい・特定コンポーネントが崩れる | `⬆️ Tamagui を v1.144.4 から v2.7.7 へ更新` |

`git revert <commit>` で単体で戻せる。

2 往復（修正 → 目視）で収束しないなら、深追いせず PR ごと閉じて v1.144.4 に戻す。
v3 が beta に入っている（3.0.0-beta が 2026-09-18 に公開）ので、
v2 で粘るより v3 の移行にまとめたほうが安い。
